Wandall Kodi Repository

Official download & automatic update hub for Wandall Live TV on Kodi (Xbox, Firestick & Android).

📥 Download Wandall Repository Zip (v1.0.0) 📦 Download Wandall Add-on Directly (v1.3.2)
How to install on Xbox / Firestick:
  1. Download repository.wandall-1.0.0.zip.
  2. Open Kodi → Settings (Gear) → Add-ons.
  3. Select Install from zip file → select the downloaded zip.
  4. Once installed, click Install from repository → Wandall Repository → Video add-ons → Wandall → Install / Update to v1.3.2.
